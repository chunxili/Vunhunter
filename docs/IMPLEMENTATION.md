# PRD 功能覆盖与工程说明

本次实现以 5 项目端到端演示为交付边界。以下状态区分实际本地业务能力与尚待接入的服务，避免将 PRD 目标误报为已验收。

| 需求 | 本地实现 | 待完成能力 |
|---|---|---|
| R1 情报聚合 | 多源分类、搜索、筛选、自定义源配置 | 外部采集、增量同步、1 小时采集 SLA |
| R2 SBOM | 5 种格式导入、精确 SemVer 匹配 | 完整生态版本、CPE/PURL 映射、95% 数据集验证 |
| R3 威胁评分 | 五项权重与得分明细 | 实时社交热度、可利用性情报输入 |
| R4 智能分析 | 模板解读、攻击路径示意、项目版本及升级建议 | LLM 与证据检索、置信度校准 |
| R5 VOC | 星级、标签、评论持久化与 PM 可见性 | 规模化运营度量 |
| R6 差异识别 | 不同项目版本、网络区域与托管边界并列呈现 | 实际攻击可达性验证 |
| R7 托管排除 | managed 标记、责任方显示、通报排除 | 云资源 API 自动识别 |
| R8 通报 | 服务端建单、去重、审计、站内通知 | 邮件/IM/短信与外部投递 SLA |
| R9 修复看板 | 五阶段流程、操作时间线、原因重开 | 推送更新、任务分派、验证证据附件 |
| R10 优先级 | 业务重要性 × 项目服务器规模 × 网络暴露权重，任务排序 | 实际漏洞影响服务器的精确范围 |
| R11 仪表盘 | 项目范围、指标、SLA、CSV、报告打印 PDF | 真实历史趋势、管理层多维报表 |
| R12 图谱 | 五层关系摘要投影、导入后随数据变化 | 图数据库、完整实体级关系、增量采集 |
| R13 可视化 | 拖拽、高亮、CVE 筛选、全屏 | 多维布局、全量关系探索 |
| R14 Agent | 规则查询 CVE、超高危、公网项目 | LLM 自然语言推理、查询计划与证据 |
| R15 Persona | 画像列表、轻量表单创建、验证状态 | 编辑/归档及历史版本 |
| R16 VOC Board | 报告内反馈、PM 汇聚视图 | 自动情感分析与无效反馈分类 |
| R17 需求工厂 | 3 个规则示例主题、关联反馈、纳入 Sprint | LLM 自适应聚类，非固定示例主题 |
| R18 追溯矩阵 | 需求 × 痛点 × 角色 × 优先级 × 状态 | 接入工程团队真实 Sprint |
| R19 安全 | 会话、服务端角色/项目校验、部分来源校验 | SSO、租户隔离、加密、生产安全评估 |
| R20 性能 | 本地小规模流程可运行 | 千台基准、LLM 延迟及可用性验证 |
| R21 扩展 | 源配置与前后端分层 | 插件 SDK、采集适配器与生产扩展 |

## 文件结构

```text
src/main.jsx          页面、图表、表单、弹窗与 Agent UI
src/styles.css        设计系统、响应式布局、打印样式
server/index.js       HTTP API、会话、授权、操作审计、原子持久化
server/domain.js      版本匹配、评分、SBOM 解析、角色项目投影
server/seed.js        5 项目演示资产和漏洞数据
tests/domain.test.js  领域约束测试
tests/api.test.js     HTTP 集成测试，独立临时数据
data/db.json          运行时数据，不纳入版本控制
```

后端仅监听 `127.0.0.1`。正式构建后由同一个 Express 服务提供前端文件与 API。开发服务器通过 Vite 代理 API。生产化建议独立身份层、PostgreSQL、任务队列及可替换图存储，并按租户维度对所有读写建立授权边界。
